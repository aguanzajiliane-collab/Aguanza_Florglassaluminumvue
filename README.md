# Flor Glass & Aluminum Works — Vue Storefront

A Vue 3 + Vite product catalog for glass, aluminum windows, jalousie windows, and steel materials. The product collection uses locally stored SVG product illustrations so the catalog images load without depending on third-party image URLs.

## Run locally

1. Install Node.js (LTS).
2. Open this project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Product collection

- Clear, green, blue, gray, bronze, frosted, and tempered glass
- Aluminum jalousie window
- Aluminum sliding window
- Steel bar

Prices are illustrative starter values only. Confirm actual stock, dimensions, and quotations with the business before publishing. Authentication in this starter is frontend-only and is not production-grade.
